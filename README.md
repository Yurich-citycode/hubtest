# SevastopolAI · СитиКод · CrimeaRWA — by YuRich · рабочий репозиторий

Здесь всё для запуска: модель клуба, экономика до копейки, документы, тексты, патчи бота и сайта, студия шаблонов.
Сайт — отдельный репозиторий `YuRichHUB`. Бот — `SevastopolAIbot`.

## Начни отсюда

1. **`ЗАПУСК.html`** — открой двойным щелчком. Один файл, работает без интернета:
   - **Старт** — главное за 30 секунд и чек-лист запуска (галочки сохраняются в браузере);
   - **Калькулятор** — все цены, налоги, комиссии, места, возвраты, реклама, XP в рублях; меняй допущения и скачай новый `params.json`;
   - **Партнёру** — слайдеры «выгодно или нет» для встречи с заведением;
   - **Сценарии** S1–S5, **XP**, **Тексты** с кнопкой «Копировать», **Документы** с поиском.
2. **`docs/00-СТАРТ-ЗАВТРА.md`** — тот же чек-лист текстом.

## Как поменять цифру

```bash
pip install openpyxl formulas          # один раз
# 1. правишь economics/params.json (или в ЗАПУСК.html → Калькулятор → «Скачать params.json»)
python tools/build.py                  # 2. пересобрать документы, Excel, ЗАПУСК.html, студию
python tools/check.py                  # 3. проверка: Excel = Python до копейки, документы актуальны
```

`check.py` падает, если: Excel и Python расходятся хоть на копейку; цифры в документах поправлены руками и не совпадают с моделью; в тексте есть «17,5%», «без возврата» и другие запрещённые формулировки; HTML ссылается на внешние файлы. Последний прогон: 321 из 321.

Если меняются значения XP в боте: `python economics/xp_simulator.py --bot ../SevastopolAIbot`, затем `build.py`.
