# Пульт YuRich · City Code

Один файл — **`index.html`**. Скачай и открой двойным щелчком: интернет не нужен.

Внутри: чек-лист запуска, деньги для разного числа участников (для тебя и для партнёров), калькулятор для партнёра, правила клуба и XP, реклама, готовые тексты, кандидаты в партнёры, студия шаблонов, справка и промты для обновления бота и сайта.

Галочки, статусы кандидатов и работы в студии сохраняются в браузере. Кнопка «👁 Показать гостю» скрывает внутренние вкладки.

Старые документы, модель и исходники студии остались в истории git (коммит `ddfdd90`).
