# City Code · YuRich

Два файла. Оба работают без интернета: скачать и открыть двойным щелчком.

| Файл | Для кого | Что внутри |
|---|---|---|
| **`index.html`** | людям и партнёрам | клуб и тарифы, путь XP, калькулятор и условия для заведений, реклама, вопросы |
| **`team.html`** | команде | задачи с ролями (YuRich, Sergeich, Юристик, Бухгалтерка, Оперейтор, Патентник), деньги владельца, доход партнёра, бот (XP, команды, сервер), кандидаты, тексты, студия, справка, промты и патчи для бота и сайта, промт для домена |

Деньги владельца есть только в `team.html`. Галочки, статусы кандидатов и работы в студии сохраняются в браузере.

Старые документы, модель и исходники студии лежат в истории git (коммит `ddfdd90`).
