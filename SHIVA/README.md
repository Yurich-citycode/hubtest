# SHIVA — комплект кампании «Пепел и Пёс»

Готовый двухнедельный запуск для ShivaInu (`$SHIVA`) в паре с канонической SHIB на Solana.

## Что где лежит

| Файл | Содержание |
| --- | --- |
| [`index.html`](index.html) | Интерактивный сайт: 14 глав, пост дня, X/TG share, задания, конструктор постов, стена мантр, проверка адресов |
| [`DATA.md`](DATA.md) | Досье: токен, StonkFun, реварды, Sunrise, SHIB, снимок рынка, источники и статус каждого факта |
| [`CONCEPT.md`](CONCEPT.md) | Философия Шивы → механика токена → герои, язык, вирусные механики, название серии |
| [`PLAN-14DAYS.md`](PLAN-14DAYS.md) | Календарь на 14 дней, слоты X/TG, главы, KPI, сценарии реакции и чек-лист старта |
| [`posts/week-01.md`](posts/week-01.md) | Готовые тексты дней 0–7: X-треды, короткие X-посты, ритуалы, длинные RU/EN-посты Telegram |
| [`posts/week-02.md`](posts/week-02.md) | Готовые тексты дней 8–14 и финальный закреп |
| [`RAID-KIT.md`](RAID-KIT.md) | Цитаты Sunrise/StonkFun, реплаи, ответы на FUD, словарь и дисклеймеры |
| [`cover-specs/`](cover-specs/) | 15 JSON-спецификаций обложек |
| [`covers/`](covers/) | 14 готовых обложек 1600×900 + `og.png` для сайта |

## Публикация

Сайт статический и не требует сборки. После публикации GitHub Pages адрес:

```text
https://yurich-citycode.github.io/YuRichHUB/SHIVA/
```

Обложки пересобираются штатным генератором репозитория:

```bash
cd brand/covers
npm install
node render.js ../../SHIVA/cover-specs/day01.json --out ../../SHIVA/covers/day01.png
```
