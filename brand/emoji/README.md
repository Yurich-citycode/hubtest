# CityCode / YuRich Hub — премиум-эмодзи для статуса в Телеграме

Три статичных кастом-эмодзи 100×100 (WEBP), собранных из исходных фото
в корне репозитория скриптом [`make_emoji_photo.py`](./make_emoji_photo.py).

| Файл | Что это | Фон |
| --- | --- | --- |
| [`citycode.webp`](./citycode.webp) | Синяя плитка логотипа **CityCode** (скруглённые углы) | прозрачный |
| [`keys.webp`](./keys.webp) | Брелок-карабин с шестью бирками | прозрачный (чёрный убран) |
| [`yurichhub.webp`](./yurichhub.webp) | Блок надписи **«YuRich Hub»** с постера | тёмно-бордовый |

Все три — ровно **100×100 px**, формат **WEBP**, вес **< 64 КБ**
(фактически 5–19 КБ), с прозрачностью там, где она нужна.

Превью для быстрой проверки: [`emoji_preview.png`](./emoji_preview.png)
(общий лист ×4) и отдельные `*_preview_x4.png`.

## Требования Telegram к кастом-эмодзи

Кастом-эмодзи живут в тех же стикерпаках, что и стикеры, но с другим
размером — **строго 100×100 px, квадрат** (это не ресайз стикера 512×512,
а отдельная отрисовка: мелкие детали на 100 px «плывут»).

### Статичный эмодзи (наш случай)
- Формат: **WEBP** или **PNG**
- Размер: **ровно 100×100 px**
- Вес файла: **до 64 КБ**
- Прозрачный фон — где нужно (альфа поддерживается)
- Отправлять **как файл** (документом), не «сжатым фото»

### Видео-эмодзи (если понадобится анимация)
- Контейнер/кодек: **WEBM, VP9**
- Размер: **ровно 100×100 px**
- Длительность: **до 3 сек**, частота: **до 30 fps**
- **Без аудиодорожки** (пустая звуковая дорожка — частая причина отказа)
- Прозрачность (альфа) поддерживается, рекомендуется зациклить
- Вес файла: **до 256 КБ** (у Telegram лимит для видео выше, чем 64 КБ
  у статики; если хочется уложиться в 64 КБ — это просто «с запасом»)

### Векторный эмодзи (альтернатива)
- Формат: **.TGS** (Lottie), 512×512, до 3 сек, 60 fps, до 64 КБ

### Прочие лимиты набора
- В набор эмодзи помещается до **200** эмодзи.
- Набор создаётся пачкой из **1–50** штук, остальное — добавлением позже.

Официально: <https://core.telegram.org/api/stickers>

## Как загрузить набор через @Stickers

1. В Telegram найдите бота **@Stickers** и откройте чат.
2. Отправьте команду **`/newemojipack`**.
3. Задайте **название** набора.
4. Загрузите файлы **как ФАЙЛ** (в приложении: «Файл», не «Фото/сжать»):
   `citycode.webp`, `keys.webp`, `yurichhub.webp`.
5. После каждого файла бот попросит **привязать к нему обычный эмодзи**
   (например 🟦 к `citycode`, 🔑 к `keys`, 🅱️/✍️ к `yurichhub`) — это
   «подпись»-заменитель для тех, у кого нет Premium.
6. Отправьте **`/publish`**, задайте **short name** (ссылку `t.me/addemoji/...`).
7. Готово: набор доступен по ссылке; ставить кастом-эмодзи в статус/текст
   может пользователь с **Telegram Premium**.

> Не находите кнопку создания? Обновите Telegram — редактор эмодзи/стикеров
> прячется за «＋» на панели эмодзи (мобайл и десктоп).

## Как пересобрать эмодзи из исходников

Скрипт берёт исходные фото **из корня репозитория**:
`CityCode.png`, `keychain.webp`, `yurichhub.jpg` — и кладёт результат
рядом с собой, в `brand/emoji/`.

```bash
pip install --break-system-packages pillow
python3 brand/emoji/make_emoji_photo.py            # собрать три .webp
python3 brand/emoji/make_emoji_photo.py --preview   # + превью ×4 и общий лист
```

### Что делает конвейер
1. **Кроп по объекту.**
   - `citycode` — по синим пикселям плитки, затем чистые **скруглённые углы**;
   - `keys` — по видимому брелоку;
   - `yurichhub` — по блоку надписи «YuRich Hub» (правый край режется до руки
     на постере; заходящая в кадр кисть с кольцами закрашивается бордовой
     «бумагой», а белые буквы восстанавливаются поверх — надпись остаётся целой).
2. **Чёрный фон → прозрачность заливкой ОТ УГЛОВ (floodfill).** Убирается
   только фон, связанный с углами кадра, поэтому **чёрный карабин и тёмные
   бирки не превращаются в «призраков»** (глобальное «убрать всё чёрное» их
   бы стёрло). Исходники, уже пришедшие с готовой альфой (напр. `keychain.webp`,
   `CityCode.png`), используются как есть — скрипт это определяет сам.
3. **Вписывание объекта в квадрат** (прозрачные поля или цвет фона постера).
4. **Даунскейл рабочих 600 px → 100 px фильтром LANCZOS** + контраст /
   насыщенность / **UnsharpMask**, чтобы мелкие детали не «поплыли».
5. **Сохранение WEBP lossless, ровно 100×100, до 64 КБ** (при переборе лимита
   скрипт автоматически поджал бы качество — для 100×100 практически не нужно).

### Подгонка кропа
Координаты кропа заданы долями в функциях `build_citycode()`,
`build_keys()`, `build_yurichhub()` в `make_emoji_photo.py` — правьте там и
перезапускайте с `--preview`, чтобы сразу увидеть результат.
