# WALLY — эмодзи-набор «RWA Elephant» для Телеграма

Шесть квадратных кастом-эмодзи со слоном **WALLY**, маскотом
RWA Foundation ([@RWAFoundation_](https://x.com/RWAFoundation_)).

Персонаж снят с исходных фото в корне репозитория
(`слон эмодзи.jpg`, `слон эмодзи2.jpg`, `слон эмодзи3.jpg`) — это
обязательное условие: эмодзи делаются именно с оригинального WALLY.

Стиль по ТЗ: простой жирный вектор-мультяшка, светло-серая/серебристая
заливка, толстые чёрные контуры, крупные округлые уши, чёрные очки с
белыми зигзаг-бликами на линзах, открытая улыбка с маленькими белыми
бивнями и зубами, лёгкий ракурс три четверти влево. Минимум деталей,
высокий контраст — читается в размере 100 px.

Оранжевый и золотой в головных убора́х — кивок фирменному
«loud orange» из брендбука RWA Foundation.

## Что лежит в папке

- `raw/` — исходные AI-генерации (белый фон / прозрачный фон,
  1024–1254 px). Базовый `wally.png` — вариант, выбранный вручную
  из двух кандидатов; пять остальных генерировались с ним как
  с референсом персонажа.
- `png512/` — мастера **512×512 PNG**: прозрачный фон, белый
  стикер-контур ~9 px, контент ~90% кадра. Подходят и как стикеры.
- `webp100/` — готовые к загрузке кастом-эмодзи: **ровно 100×100,
  WEBP lossless, 5–10 КБ** (лимит Telegram — 64 КБ).
- `preview.png` — общий лист: все шесть на «шахматке» (видно
  прозрачность) + строка 100 px и 44 px на тёмном фоне (как в чате).
- `make_wally_emoji.py` — пересборка `raw/` → `png512/` + `webp100/`.

## Конвейер (что делает скрипт)

1. **Фон → прозрачность** заливкой ОТ УГЛОВ (floodfill): убирается
   только фон, связанный с краями кадра, поэтому белые бивни и зубы
   внутри морды не страдают. Генерации с уже готовой альфой
   (базовый `wally.png`) используются как есть.
2. **Ink-буст** (только для вариантов с шапками): степенная кривая
   приводит мягкие серые контуры и линзы очков к «жирному чёрному»
   стилю базового WALLY. Насыщенные цвета (оранжевая кепка, золотая
   корона) не трогаются — кривая применяется только к нейтральным
   пикселям.
3. **Белый стикер-контур** ~9 px (дилатация альфы) — эмоджи отлично
   видны и на светлых, и на тёмных фонах чата.
4. **Вписывание в квадрат 512×512** по центру, заполнение ~90%.
5. **Даунскейл до 100×100** LANCZOS + UnsharpMask только по RGB
   (альфа не трогается, чтобы не было ореолов), WEBP lossless < 64 КБ.

## Загрузка в Телеграм

Требования и шаги — как у остальных наборов, см.
[`../README.md`](../README.md). Коротко: @Stickers → `/newemojipack` →
название → отправить файлы из `webp100/` **как ФАЙЛ** (не «сжать фото») →
привязать обычные эмодзи из таблицы выше → `/publish`.

## Пересборка

```bash
pip install --break-system-packages pillow
python3 brand/emoji/wally/make_wally_emoji.py             # png512 + webp100 + preview
python3 brand/emoji/wally/make_wally_emoji.py --only wally_cap   # один стикер
```

Подбор параметров: `OUTLINE_PX` (белый контур), `BLACK_PX`
(восстановление чёрного контура), `FILL` (заполнение кадра),
`ink_boost(power, knee, spread)` (жирность чернил).
