# Обложки YurichHub

Один каркас на все посты. Меняется заголовок, цифры и одно предложение. Фон, шрифт, глитч, знак `YURICHHUB` и имя серии не придумываются заново.

Спека для агента, её надо прочитать до любой новой картинки: `YURICHHUB-STYLE.md`.

Канон, с которого снят каркас: `reference/xalgo-cover.png`. Рядом лежат английская обложка и четыре слайда карусели.

## Как заказать обложку

Написать четыре вещи:

1. Модуль: `sevastopol`, `citycode`, `rwa`, `course`, `glossary`, `cfa`, `research` или `hub`.
2. Заголовок. Короткий, 2–4 слова. `X ALGO HACK`, `НЕ ТОКЕН`, `CITY CODE`.
3. Одно предложение, которое человек унесёт, если пост не откроет.
4. Две–четыре цифры, которые уже есть. Не выдумывать четвёртую «для ритма».

Дальше агент не рисует нейросетью. Он подставляет это в `covers/render.js` и отдаёт PNG 1600×900.

## Как собрать самому

```bash
cd covers
npm install
node render.js post.json --out ../samples/post.png
```

`post.json` — пустая анкета. Поля, которые можно не трогать: `series` и `footerNote`. Их подставит модуль.

Или без файла, прямо флагами:

```bash
node render.js --module cfa --title "НЕ ТОКЕН" \
  --subtitle "СБОРКА ВЫПУСКА ЦФА ДО ПЛОЩАДКИ" \
  --body "Инвестор покупает не бизнес. Он покупает право получить деньги." \
  --stat "80|ТЫС. РУБ. РАЗБОР|pink" --stat "0|ДЕНЕГ НА МОЙ СЧЁТ|lime" \
  --date 09.2026 --out ../samples/post.png
```

`--stat` повторяется до четырёх раз: `цифра|подпись|цвет`. Цвета: `lime`, `ink`, `pink`, `gold`, `bronze`.

Готовые примеры: `covers/examples/`. Картинки с них: `samples/`. Все девять рядом: `samples/board.png`.

## Что не менять

- Фон `#0A0A0A`, лайм `#D7FF3D`, золото `#C8A24A`, розовый `#E8377E`, чернила `#F3F1EA`.
- Русский заголовок — Oswald. Английский — Anton. Anton на кириллице ломает обложку.
- `YURICHHUB` внизу слева, `HUB` лаймом, без пробела. Имя серии справа тоже лаймом.
- Углы острые. Тени жёсткие, без размытия. Глитч один, на первой строке заголовка.
- Кремовая страница курса, комикс и офер ЦФА в ленту не переносятся. Обложка поста про них всё равно тёмная.

Модуль узнаётся рубрикой и цветом первой карточки, не новым постером. Sevastopol — золото. Crimea RWA — бронза `#C98A4E`. Курс, глоссарий и ЦФА — розовый. City Code и разборы — лайм.
