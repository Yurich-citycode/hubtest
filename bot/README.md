## Новые переменные `.env`

| Переменная | По умолчанию | Что это |
|---|---|---|
| `CITYCODE_GRANT_DAYS` | `365` | Сколько дней членства даёт ранг City Code (7000 XP). Было 180 |
| `CITYCODE_GRANT_QUOTA` | `30` | Сколько грантов за ранг на транш (10% от 300 мест) |
| `CLUB_SEATS_OPEN` | `0` (не проверять) | **15 × подписанные партнёры.** Бот предупредит при `/paid`, если участников больше |
| `PRIVACY_URL` | `https://yurich-citycode.github.io/YuRichHUB/privacy.html` | Политика ПДн — ссылка в приветствии. Страница — в патче сайта |

## Команды владельца (`/help_admin` в боте)

| Команда | Что делает |
|---|---|
| `/admin` | Статистика |
| `/sources` | Откуда пришли люди: паспорта · дошли до 100 XP · участники CC по каждой `src_`-метке |
| `/paid user_id basic\|founder [referrer_id]` | **Оплата года:** +365 дней, тариф; пригласившему +120 XP и +30 дней. Предупредит, если мест больше нет |
| `/ref_paid referrer_id` | Вручную начислить бонус за оплатившего приглашённого |
| `/set_member user_id days source` | Членство руками (`partner` — владельцу точки, `rank` — бонус Амбассадору) |
| `/xp_place user_id` | Место принято, +60 |
| `/xp_route user_id` | Маршрут принят, +100 |
| `/xp_fix user_id` | Правка принята, +15 (до 3 в день) |
| `/xp_review user_id` | Отзыв принят, +10 (до 2 в день) |
| `/checkin user_id event_id` | Чек-ин на событии, +80 |
| `/partner_node user_id node_id` | Партнёр-узел подключён, +200; потом +80 раз в 30 дней |
| `/revoke_xp user_id amount причина` | Снять XP (накрутка) |

`user_id` человека видно в `/admin` или в пересланном сообщении. Человек должен хоть раз нажать `/start`.

## Ссылки с метками

`https://t.me/SevastopolAIBot?start=src_<метка>` — латиница, цифры, `-` и `_`. Примеры: `src_qr-kofeinya-na-uglu`, `src_pub-sevnews-1102`, `src_post-cc-launch`. Реферальные ссылки участников бот выдаёт сам (`ref_<id>`).
