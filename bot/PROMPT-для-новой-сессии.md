# Промпт для новой сессии: доработка бота @SevastopolAIBot

Скопируй всё ниже в новую сессию агента с доступом к репозиторию `Yurich-citycode/SevastopolAIbot`.

---

Ты работаешь с Telegram-ботом Sevastopol AI (aiogram 3, один файл `sevastopolaibot.py`, состояние в `bot_state.json`, база мест в `Sevastopol AI База.xlsx`, тесты — `python3 tests/test_carousels.py`, скрипт печатает «ИТОГ: N прошло, M упало»).

**Шаг 0.** Если в репозитории ещё нет изменений v1.1 (поиск `CITYCODE_GRANT_QUOTA` в `sevastopolaibot.py` ничего не находит), примени патч из `Yurich-citycode/hubtest`: `bot/patches/0001-v1.1-xp-referrals-sources-admin.patch` (`git apply`). Тесты должны дать 195/0. Описание v1.1 — `hubtest/bot/README.md`. Модель клуба — `hubtest/docs/02-city-code-v1.1.md`, XP — `hubtest/docs/04-xp.md`.

**Задачи (каждая — с тестами в `tests/test_carousels.py`, стиль кода и тестов — как в файле):**

1. **QR-чек-ин на событии.** `?start=chk_<event_id>_<код>`: код — 6 символов, задаётся командой владельца `/event_code event_id` (бот генерирует и хранит код с датой; действует 12 часов). Скан → +80 XP (`EVENT_CHECKIN`) один раз на человека на событие. Неверный или просроченный код → вежливый отказ без XP.
2. **Лист ожидания.** Кнопка «Встать в список» в разделе City Code и команда `/waitlist` у пользователя. Хранить `WAITLIST` в состоянии: user_id, дата, ранг на момент записи. Порядок: сначала XP ≥ 800 (Проводник+), внутри — по дате. Команды владельца: `/waitlist_show` (первые 30 с позицией), `/waitlist_pop N` — выдать N первых (бот пишет им сообщение «Место открылось», текст в `hubtest/docs/11-тексты-для-запуска.md`, текст 8 — адаптируй). При `/paid` человек удаляется из листа.
3. **Срок хранения ПДн.** Команда владельца `/purge_inactive` (сначала выводит число паспортов без активности 365+ дней и без активного членства, удаляет после `/purge_inactive confirm`). Удалять из `PASSPORTS`, `REFERRALS` и аналитики; записи об оплатах не трогать.
4. **Бэкап.** Раз в сутки копия `bot_state.json` → `backups/bot_state-YYYY-MM-DD.json`, хранить 14 последних.
5. **Не трогать:** значения XP, пороги рангов, тексты City Code, цены — это решения владельца, они уже согласованы в v1.1.

**Проверки перед сдачей:** `python3 -m py_compile sevastopolaibot.py`; все тесты зелёные; `python3 tools/check_base.py` (ошибки базы — это данные, не код: дубль «Супертяж», 5 чужих фото — не чинить кодом, только сообщить). Токен бота не трогать и не выводить.
