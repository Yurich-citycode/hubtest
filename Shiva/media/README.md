# Фото или GIF для buybot

1. Загрузите сюда файл, например `buy.jpg`, `buy.png` или `buy.gif`.
2. В файле `Shiva/.env` укажите путь:
   - `MEDIA_FILE=media/buy.jpg` — фото;
   - `MEDIA_FILE=media/buy.gif` — GIF.
3. Оставьте `MEDIA_TYPE=auto`.
4. Перезапустите бота и отправьте `/test`.

Файл картинки можно добавить в GitHub через **Add file → Upload files**. Не кладите сюда секреты и личные фотографии.
