# Shiva — простая инструкция по запуску buybot

Папка `Shiva` содержит программу Telegram-бота, пример текста объявления и место для фото/GIF. GitHub только хранит эти файлы: **сам бот работает, только пока запущена программа на компьютере или сервере**.

## Сначала — безопасность

Токен, который ты отправил в переписке, уже нельзя считать секретным.

1. Открой в Telegram **@BotFather**.
2. Выбери своего бота и отзови старый токен командой `/revoke`.
3. Получи новый токен.
4. Не отправляй новый токен в чат и не добавляй его на GitHub. Вставь его только в свой личный файл `Shiva/.env`.

## Запуск на компьютере: проверить, что всё работает

Ниже шаги для Windows. На Mac/Linux команды приведены отдельно.

### 1. Скачай проект с GitHub

Открой папку `Shiva` в репозитории и скачай проект через **Code → Download ZIP**. Распакуй архив. Внутри должна быть папка `Shiva` с файлами `package.json`, `.env.example` и `message.html`.

> Папка находится в ветке `arena/63c93a3b-hubtest`. Если GitHub показывает другую ветку, выбери эту в списке веток.

### 2. Установи Node.js

Это бесплатная программа, которая запускает бота. Скачай версию **LTS** с [nodejs.org](https://nodejs.org/) и установи её. Если установщик спросит — оставь стандартные настройки.

### 3. Создай личные настройки

1. Открой папку `Shiva`.
2. Щёлкни по адресной строке проводника, напиши `powershell` и нажми Enter. Откроется окно команд.
3. Скопируй команду и нажми Enter:

```powershell
Copy-Item .env.example .env
```

4. Открой файл настроек:

```powershell
notepad .env
```

5. Вставь **новый** токен после `TELEGRAM_BOT_TOKEN=`. Замени `ВАШ_ТИКЕР` на тикер своего токена, например `SHIVA`. Сохрани файл.

Остальные параметры пока можно не менять. Адрес твоего токена уже вписан. Не публикуй `.env` и не присылай его содержимое.

### 4. Запусти бота

В том же окне PowerShell выполни:

```powershell
npm start
```

Окно должно оставаться открытым. Пока оно открыто и компьютер включён, бот работает. Чтобы остановить бота, нажми `Ctrl+C`.

### 5. Подключи бота к группе

1. Добавь бота в свою Telegram-группу. Проверь, что ему разрешено отправлять сообщения.
2. В группе отправь `/chatid@ИмяТвоегоБота` — вместо `ИмяТвоегоБота` укажи username бота из Telegram.
3. Бот ответит ID группы. Скопируй его.
4. Останови программу клавишами `Ctrl+C`.
5. Снова открой `.env` командой `notepad .env`. Вставь ID после `TELEGRAM_CHAT_ID=`. ID группы часто начинается с `-100`; минус тоже нужно скопировать.
6. Сохрани файл и снова запусти `npm start`.
7. В группе отправь `/test`. Бот пришлёт тестовое сообщение и, если настроено, картинку/GIF.

Если во время настройки уже прошла покупка, бот сохранит её и отправит после того, как ты укажешь ID группы. Старые сделки, которые были до самого первого запуска, он не отправляет.

### Mac или Linux

В папке `Shiva` открой Terminal и выполни:

```bash
cp .env.example .env
nano .env
npm start
```

В `nano`: вставь токен, замени тикер, сохрани `Ctrl+O`, Enter, выйди `Ctrl+X`. Чтобы остановить бота, нажми `Ctrl+C`.

## Как добавить своё фото или GIF

1. Положи фото или GIF в папку **`Shiva/media`**. Например, назови файл `buy.jpg` или `buy.gif`.
   - Фото: `.jpg`, `.jpeg` или `.png`.
   - GIF: файл `.gif`.
2. Открой `Shiva/.env`.
3. Найди строку `MEDIA_FILE=` и укажи путь к своему файлу:

```dotenv
MEDIA_FILE=media/buy.jpg
```

Для GIF напиши:

```dotenv
MEDIA_FILE=media/buy.gif
```

4. Оставь `MEDIA_TYPE=auto`.
5. Сохрани `.env`, перезапусти бота и отправь `/test`.

Чтобы добавить картинку в GitHub: открой `Shiva/media`, нажми **Add file → Upload files**, выбери файл и подтверди загрузку. Если запускаешь скачанную копию проекта на компьютере, положи картинку и в её папку `Shiva/media` тоже. Файлы из GitHub сами на компьютер не скачиваются.

Если `MEDIA_FILE=` оставлено пустым, бот отправляет только текст. Картинка/GIF прикрепляется к каждому объявлению о покупке.

## Где поменять текст и добавить эмодзи

Открой файл **`Shiva/message.html`** в обычном текстовом редакторе, например Notepad. Это отдельный файл только для текста объявления. Добавляй туда свои слова, переносы строк и эмодзи — например 🐕 🚀 🔥 💎. После изменений перезапусти бота.

Оставь в тексте фигурные скобки с названиями — бот заменит их данными сделки:

- `{token}` — тикер токена;
- `{token_amount}` — сколько токенов купили;
- `{quote_amount}` — сколько монет пары потратили;
- `{quote_symbol}` — подпись монеты пары, сейчас `SHIB`;
- `{buyer}` — ссылка на кошелёк покупателя;
- `{tx_url}` — ссылка на транзакцию;
- `{token_url}` — ссылка на страницу токена Stonkfun.

Например, можно заменить весь текст на такой:

```html
🚀 <b>Покупка {token}!</b>

💰 Куплено: <b>{token_amount} {token}</b>
🐕 Потрачено: <b>{quote_amount} {quote_symbol}</b>
👤 Кошелёк: {buyer}

<a href="{tx_url}">Смотреть покупку</a> · <a href="{token_url}">Открыть токен</a>
```

Теги `<b>текст</b>` делают текст жирным, `<i>текст</i>` — курсивом. Теги можно удалить, если оформление не нужно, но фигурные скобки с данными сделки лучше оставить. Пиши текст в `message.html`, а не в `.env`.

## Как оставить его работающим постоянно

- **На домашнем компьютере:** оставь компьютер включённым, не закрывай окно с `npm start` и отключи автоматический сон. Если компьютер выключить или закрыть окно, бот остановится.
- **В облаке:** нужна отдельная Linux-машина, которая всё время включена. У некоторых облачных сервисов есть бесплатные машины, но условия и доступность меняются. Бесплатную работу навсегда никто не гарантирует. Сам код бота бесплатный; у бесплатного Solana RPC тоже могут быть лимиты.

Чтобы компьютер или облачная машина перезапускали бота автоматически, на Linux используется `systemd`. Пример настройки и команды есть внизу этого файла. Если пока не знаком с Linux, сначала проверь бота на своём компьютере по шагам выше.

### Автозапуск на Linux-машине (дополнительный шаг)

Сначала скопируй папку `Shiva` на Linux-машину, установи Node.js 20 или новее, заполни `.env`, затем в Terminal внутри `Shiva` проверь обычный запуск командой `npm start`. После проверки останови его `Ctrl+C`.

Узнай пути командами:

```bash
pwd
which node
```

Открой файл автозапуска:

```bash
sudo nano /etc/systemd/system/shiva-buybot.service
```

Вставь текст ниже. Замени `/home/ubuntu/Shiva` на путь, который показала команда `pwd`, и `/usr/bin/node` на путь, который показала команда `which node`:

```ini
[Unit]
Description=Shiva Telegram Buybot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/Shiva
EnvironmentFile=/home/ubuntu/Shiva/.env
ExecStart=/usr/bin/node /home/ubuntu/Shiva/src/index.js
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Если имя пользователя на машине не `ubuntu`, замени `ubuntu` на своё имя. Сохрани в `nano`: `Ctrl+O`, Enter, `Ctrl+X`. Затем выполни:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now shiva-buybot
sudo systemctl status shiva-buybot
```

Посмотреть, что пишет бот:

```bash
sudo journalctl -u shiva-buybot -f
```

После изменения `.env`, `message.html` или картинки перезапусти его:

```bash
sudo systemctl restart shiva-buybot
```

Не запускай одну и ту же Telegram-бот-программу сразу в двух местах: сообщения могут дублироваться.
