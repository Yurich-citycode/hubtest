## Словарь

| Правильно | Не используем |
|---|---|
| **СИТИКОД** (рус.), **CITY CODE** (лат.) | Сити Код, Ситикод, City-Code |
| **Sevastopol AI**, в ссылках **SevastopolAI** | Севастополь ИИ, SevAI |
| **YuRichRWA** | Yurich RWA, YuRich_RWA |
| **YuRich** | Юрич, Yurich (в бренде) |
| **YurichHub** (сайт) | YuRichHUB — только имя репозитория |
| **Crimea RWA** | КрымRWA. Публично — после юрлица и проверки товарного знака ⚠️ |
| **Привилегия** 3–7% | «скидка», «кэшбэк» |

- **XP** — очки активности в боте. Пороги 100 / 300 / 800 / 2000 / 4000 / 7000. Ранги: Гость города → Житель → Исследователь → Проводник → Амбассадор → Легенда города → City Code. XP не деньги и не скидка (`04-xp.md`).
- **City Passport** — номер участника в боте `CC-xxxxxx` (уникальный после патча) и физическая книжка-мерч с тем же номером.
- **Партнёр-точка (узел)** — заведение с привилегией. **Ячейка** — место партнёра в логотипе «CC», 01–20.
- **src-метка** — хвост ссылки `t.me/SevastopolAIBot?start=src_метка`: бот запоминает, откуда пришёл человек, отчёт — `/sources`.
- **ЦФА** — цифровые финансовые активы по 259-ФЗ, выпуск только через оператора из реестра Банка России. **RWA** — мировой термин для токенизации реальных активов.

## Воронка

```
 Посев / QR / карточка партнёра  (src-метка)
            │
 Sevastopol AI: /start ─▶ пользуется ─▶ XP 100–800 (Житель → Проводник)
            │                                  │
 «Партнёр City Code» на карточке      путь к City Code в паспорте
            ▼                                  ▼
 Открытая встреча клуба ─▶ оплата членства ─▶ визиты к партнёрам (спрос)
            ▼
 YuRichRWA: как владеть ─▶ (будущее) ЦФА на выручку партнёра
```

| Шаг | Метрика | Цель пилота 🧪 | Где считать |
|---|---|---|---|
| Охват → старт бота | CPA за активированного (≥3 действия) | ≤ 30–50 ₽ | `/sources` |
| Старт → активен 7 дней | D7 | ≥ 25% | паспорта (`active_days`) |
| Активный → гость встречи | конверсия | 3–5% | список гостей |
| Гость → участник | конверсия | 20–30% | `/paid` |
| Участник → расход у партнёров | ₽ в месяц | ~7 000 (v1.0, проверить) | отчёты партнёров |

**Связки:** SAI → CC (плашка «Партнёр City Code», QR у партнёров, ранги ведут к City Code). CC → SAI (партнёру карточка, маршруты, анонс раз в месяц бесплатно; участники предлагают места за XP). CC → RWA (партнёры — будущие эмитенты ЦФА; участники — держатели в пределах лимитов). RWA → CC (экспертиза приводит «Основателей»-предпринимателей).
