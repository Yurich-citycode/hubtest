**Три правила запуска:**

1. **Мест столько, сколько партнёров.** По правилу v1.0 на одного партнёра приходится 15 мест. Нет подписанных партнёров — значит, продаёшь не места, а **лист ожидания**. Первые 50 мест «Основатели» открываются после 4 подписанных партнёров.
2. **Деньги — только официально.** Самозанятость (НПД) оформляется за 10 минут в «Мой налог». Оплату принимай по СБП (≤0,7%), а не картой через агрегатор (4,27% с НДС на комиссию). Чек в «Мой налог» — на каждую оплату. Мерч самозанятому перепродавать нельзя — набор «Основателей» выдаёшь после открытия ИП (подать заявление через Госуслуги, 3 рабочих дня).
3. **Ничего не обещаем сверх написанного.** Никакой доходности, «доли в городе», «скидок для всех». Привилегия 3–7% у партнёров, события, люди, статус. Возврат — по формуле из оферты.
