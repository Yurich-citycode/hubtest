# 04 · XP v1.1 — очки активности

> Значения XP живут в коде бота (`sevastopolaibot.py`, после патча `bot/patches/0001-…`). Таблицы ниже собирает `tools/build.py` из `economics/out/xp_sim.json`. Это результат прогона **реальных функций бота** с подменённым временем: `python economics/xp_simulator.py --bot ../SevastopolAIbot`.

## Принцип

**City Code можно купить или заслужить. Заслужить — значит помогать городу:** добавлять места, водить маршруты, приходить на события, приводить людей. За кнопки много не дадут.

- XP **не деньги**, не скидка и не продаются. **За оплату XP не начисляется** — иначе ранг можно купить.
- Порог City Code 7000 XP не снижаем — это статус.
- Самые ценные действия (место, маршрут, чек-ин) подтверждает владелец командой — без подтверждения XP нет.

| XP | Ранг | Что даёт | Стоит нам |

<!-- /AUTO:xp_sim -->

**Что исправила v1.1:**
1. В v1.0 **фармер кнопок обгонял вкладчика** (317 против 396 дней до 7000). Теперь вкладчик быстрее (438 против 698).
2. Амбассадор (приводит людей и места) идёт почти так же — 273 дня. Ему ничего не урезали.
3. Обычному жителю City Code через XP недостижим — больше 6 лет и в v1.0, и в v1.1. Это честно: XP — путь для тех, кто строит город; остальные покупают членство.
4. Партнёру XP-гонка не нужна: владелец точки получает членство на срок партнёрства (`/set_member user_id 365 partner`).

## Ошибки бота, которые исправил патч v1.1

| Было | Стало |
|---|---|
| +5 XP за простое нажатие «Предложить место» | 0; XP — только когда место принято (`/xp_place`) |
| Потолок 22 XP в день — фармер обгонял вкладчика | 10 XP в день |
| Реферальный бонус за любого, кто нажал ссылку (включая старых пользователей) | Только за нового; себя пригласить нельзя |
| +40 за активного друга считалось по аналитике (буфер 2000 строк — ломается на масштабе) | По дням активности в паспорте (`active_days`) |
| Номер `CC-` + 6 последних цифр ID мог совпасть у двоих | Уникальный номер; старые совпадения чинятся при старте |
| Нет `src_`-меток — непонятно, откуда люди | `?start=src_метка`, отчёт `/sources` |
| Грант City Code 180 дней без лимита | 365 дней, квота 30 (`CITYCODE_GRANT_DAYS`, `CITYCODE_GRANT_QUOTA`) |
| Месячное членство `CLUB_PAID_MONTH` | Удалено: членство только годовое |
| «Заявка без очереди» за ранг | Приоритет в листе ожидания, место не бесплатное |
| Не было команд на маршрут, правку, отзыв | `/xp_route`, `/xp_fix`, `/xp_review` (команды на место, чек-ин, узел и снятие XP были и раньше) |
