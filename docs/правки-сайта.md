# Правки сайта YurichHub (репозиторий `YuRichHUB`)

Готовый патч — `site/0001-правки-сайта.patch`. Применить:

```bash
cd YuRichHUB
git apply ../hubtest/site/0001-правки-сайта.patch
# в privacy.html подставить ФИО, ИНН, e-mail (места помечены <!--ОПЕРАТОР--> и <!--EMAIL-->)
git add -A && git commit -m "Сайт: привилегии вместо скидки, реальные цифры, без доходности, privacy.html" && git push
```

## Что сделать руками

- В `privacy.html` подставить ФИО, ИНН, e-mail. Обещанные там сроки хранения (1 год после последнего действия, оплаты — 5 лет) **бот сам не выполняет**: раз в квартал удаляй старые паспорта из `bot_state.json` или поручи доработку бота (промпт — `bot/PROMPT-для-новой-сессии.md`).
- Удалить из репозитория сайта неиспользуемые `hermes.jpg` и `nebank.png` (на них нет ссылок).
- cfa.html, блок «До счёта: фикс + 3–7%, я веду людей» — привлечение инвесторов за процент от собранного. ⚠️ Показать юристу: не попадает ли под деятельность инвестиционного советника/брокера.
- Если положишь комиксы 7–13 — имена `comics7.jpg` … `comics13.jpg` в корне сайта.
